# 三地红利看板（新加坡 + 港股 + A股）· 设置与使用

每个交易日 **17:30（新加坡时间）** 自动：
1. 拉取三地行情和近 11 年分红记录（新加坡用 yfinance，A股/港股用 akshare）
2. 每只股票算：近 12 个月分红、税后股息率、**过去 10 年股息率分位** → 买入区 / 持有区 / 减仓区，
   日/周/月布林带、股息率网格、计划触发、AH 溢价
3. 更新网页看板，有提醒就发邮件

全部免费，一次性设置约 20 分钟。

---

## 隐私
- GitHub 免费版要**公开仓库**才能开网页：股票清单、计划价、行情数据别人能看到。
- **持仓、现金、目标比例、复盘笔记只存在你自己设备的浏览器**，不上传。换设备用“配置”页的导出 / 导入。

## 设置步骤
1. **Gmail 应用专用密码**：Google 账号 → 安全性 → 开两步验证 → 搜“应用专用密码” → 生成 16 位密码
2. **建仓库**：github.com → New repository → 名字 `dividend` → **Public** → Create
3. **上传**：“uploading an existing file”，拖入 `build.py`、`swing.py`、`backtest.py`、`fillstats.py`、`watchlist.yaml`、`README.md`、`docs` 文件夹 → Commit
4. **工作流**（隐藏文件夹要单独建）：Add file → Create new file，
   - 文件名 `.github/workflows/daily.yml`，粘贴本包同名文件内容 → Commit
   - 再建 `.github/workflows/backtest.yml` 同理
5. **邮箱密钥**：Settings → Secrets and variables → Actions → New repository secret
   - `SMTP_USER` = 你的 Gmail；`SMTP_PASS` = 16 位密码；`MAIL_TO`（可选）收件人
   - 想天天收日报：Variables 页加 `ALWAYS_SEND` = `1`
6. **开网页**：Settings → Pages → Deploy from a branch → `main` + `/docs` → Save
7. **第一次运行**：Actions → 红利看板 → Run workflow（约 5–8 分钟，要拉 10 年数据）。
   完成后打开 `https://你的用户名.github.io/dividend/`，手机上“添加到主屏幕”。

## 每天（约 2 分钟）
看邮件或打开看板 → 只看“低位观察”和“计划”有没有新内容 → 有就按计划执行，没有就关掉。

## 每周（约 20 分钟，建议周六）
打开“周复盘”：
- 上半部分自动列出：计划触发、★ 低位机会、持仓中偏高的、仓位和集中度提醒、近 5 日涨跌
- 按清单逐条勾选，写本周笔记（做了什么、为什么）

## 每年
分红季后看一眼各股票的“近 12 月实际分红”是否合理；预计分红会明显变化的，在 watchlist 里手动填 `dps`。

## 分批建仓 / 减仓（看板“分批建议”列 + 每只股票展开后的“分批计划”）
- 在“录入持仓 / 修改”里给每只股票填**计划占比**（这只股票最多占总资产的 %，建议 3–12%，上限 15%）
- 计划金额 = 计划占比 × 总资产（股票市值 + 现金）。**每月更新现金余额后，计划金额和每档该买多少会自动变大**，不用手动改
- **买 3 档：第一笔 50%，第 2、3 档各 25%**：股息率回到**历史中位数**以上 → 80 分位 → 90 分位（历史不足 3 年：买入线 −0.5 / 买入线 / +0.5 个百分点）。直接跌到第 2 档时，一次补到 75%。
  为什么前多后少：经验上（包括其他红利博主的实践）大部分股票只会到第 1 档，第 2、3 档很少到，平均分三份会让大量资金闲置
- **为什么第 1 档放在中位数**：模拟显示，80/90/95 起步时 5 年平均只有约 4 成资金能投出去；中位数起步 + 候选超额后约 7 成以上。真实数据结果看“建仓统计”页
- **周线跌破布林下轨时不买**，等收盘重新站上周线下轨再买（避免接正在下跌的刀）
- **股息率底线**（借鉴吴富贵）：第 1 档除了到历史中位数，税后股息率还要 ≥ 4.5%（`defaults.floor_net`），防止“历史上一直很低”的股票在 3% 就开始买
- **价格在周线布林中轨上方时不买**：股息率到了也等跌回中轨下，不追涨（显示“等回中轨下”）
- **公司评级**（watchlist 的 `rating`，或在编辑窗口里改）：A+ 有分红 + 业绩增长 / A− 横盘 / B 下滑 / B− 差。
  **计划占比按评级自动调整：A+ ×1.2，A− 不变，B 及以下减半**（调整后不超过单只上限 15%；填的时候各只按同样的基础占比填就行）；**股价跌破 250 日线时，B 及以下只买第 1 档，暂停第 2、3 档**（A 级照常按档买）。没评级的不调整。季报后在周复盘里更新
- **候选超额、先到先得**：同一部分里候选股的计划占比合计可以到目标的 **3 倍**（只买到第 1 档也能把钱投满）；同时有几只可以买时，按股息率分位从高到低分配，到该部分目标为止
- **分位窗口**：默认近 10 年；估值体系“换挡”的股票（平安、招行、中国移动等）用近 5 年（watchlist 里 `hist_years: 5`）
- **A股账户单独算**：在“配置”页填东方财富账户的人民币现金，A股的计划占比按这个账户的总额计算
- **减 2 档**：减仓线（20 分位）卖 1/3 → 10 分位再卖 1/3，**剩下 1/3 作为底仓**；按录入过的最高持股数计算，减完不会重复提示
- 港股填了 `lot` 会按手取整；单只超过组合 15% 时建议金额自动封顶；超过现金会提示
- 每次加仓前先确认分红没有削减；下跌是因为分红出问题时，不加仓

## 每月更新（“配置”页）
- 工资结余进来后（一个月或两三个月一次），在“每月更新”里填最新**现金余额**
- 页面显示：比上次多了多少、按目标比例这笔钱相当于新加坡 / 港股 / 现金各多少、每部分还可投入多少
- 现金超过 15% 的部分是**待投入资金**：不用马上买完，等股票进入买入区再按档投入
- **第 2、3 档可以动用现金垫**：某部分额度已经用完时，第 2、3 档可以用 15% 现金里的钱，但现金最少留 8%（`limits.cash_min`）
- 超过 35 天没更新，周复盘会提醒

## 买卖区规则
- 每只股票用**自己过去 10 年**的股息率（近 12 月分红 ÷ 当时股价）分布：
  当前处于高 20% → **买入区**；低 20% → **减仓区**；中间 → 持有
- 不同市场“正常股息率”不同（新加坡银行常年 5–6%，STI 3–4%），用分位比统一的 5%/4% 更公平
- 历史不足 3 年的股票改用固定规则：税后 ≥5% 买、≤4% 减
- ★ 低位机会 = 买入区 + 周线布林带下 1/3

## 波段规则（只用于波段仓）
- **仓位**：每只股票分底仓 70%（只按股息率网格）和波段仓 ≤30%。波段卖光也不动底仓。
- **主规则：滚动（借鉴吴富贵四条，“波段”页最上面）**，四条全满足才买：
  ① 日线到布林下轨（≤ 下轨 ×1.02）② 周线在中轨到下轨之间 ③ 税后股息率 ≥ 5%（`roll_min_net`）④ 股价在 250 日线之上。
  - **分两笔**：波段仓 = 计划仓位的 30%，每笔 15%。四条全满足买第一笔；之后**再次碰到日线下轨、仍在 250 日线上**补第二笔，两笔满了就不再加
  - **卖**：到周线上轨先卖一半，再涨再卖剩下的
  - **止损**：**周线收盘**（周五）跌破 250 日线 → 卖出全部波段仓，底仓不动。平时某天收在 250 日线下只是“不开新仓、盯周五收盘”，不被一两天插针骗出去
  - **转入底仓**：止损时如果评级是 A、股息率已经到了底仓某一档、底仓这一档还没买够，就点“转入底仓”，把这部分股数并进底仓（按当天价格计成本，盈亏在波段记录里结算），省一次买卖费用
  - **邮件**：“买第一笔”发给所有股票；“补第二笔 / 卖出 / 止损”只发给 watchlist 里 `roll_holding` 名单上的股票。看板“波段”页会显示这个名单该填哪些代码，买卖后照着改一下
- **补充：横盘区间**（下面这些规则）
- **什么算横盘**（全部满足）：最近 3–8 个月收盘价在一个区间里（上下沿取 97% / 3% 分位，去掉个别极端针），
  宽度 8%–30%；上沿区、下沿区各碰过 ≥2 次；周线布林带宽度 ≤20%；周线 20 均线走平（4 周内变化 ≤3%）
- **买入**：收盘进入区间下 20%，且止跌（收盘站上日线布林下轨、比前一天收高）= “买入确认”
- **卖出**：收盘进入区间上 20%
- **止损**：收盘跌破下沿 1.5% → 卖掉波段仓；收盘突破上沿 1.5% → 停止波段，不追高
- **提醒**：邮件只在信号当天刚出现时发一次
- **回测**：每只股票按同样规则滚动回测近 3 年（扣 0.4% 来回费用），页面显示笔数、胜率、累计收益、同期持有收益。
  只在回测明显为正的股票上做；半年后对比自己的“累计已实现”，不如一直持有就停
- **手动区间**：觉得自动识别不准（比如想用 K 线影线画的 4.05–4.85），在该股那一行加 `swing_box: {lo: 4.05, hi: 4.85}`；
  不想做波段就加 `swing: false`。参数在 watchlist 的 `defaults.swing` 里改

## 已知局限
- 分红用“近 12 个月实际派息”。有特别股息的年份会虚高，分红削减要等派息后才反映 —— 预计会变就手动填 `dps`
- 股息率分位只说明“相对自己历史便宜”，不代表公司基本面没问题。分红削减的公司会显得“股息率很高”，复盘时要看公告
- 波段只用收盘价识别区间（不看盘中影线），区间会比你在 K 线上目测的略窄；波段回测同样有幸存者偏差
